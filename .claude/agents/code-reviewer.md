# code-reviewer agent

Review a diff for bugs, security holes, and quality.

## When to use

- A change is ready for review.
- You want to check for security holes.
- You want to check for quality issues.

## What it does

1. Read the diff.
2. Read the connected code.
3. Emit findings ranked by severity.
