## Architectural mental model

A Pi coding-agent extension. The runtime loads index.ts through per-extension jiti and calls the `turn_end` handler after each agent turn. The handler re-reads config.json per dispatch. All turn decisions live in plan-turn.ts as two pure cores: planGate before the advisor call, planCommit after it. The seam injects every sibling capability as a thunk and owns the one cadence write (index.ts:60-61). The child-session veto is one mechanism now: a regex scan of system messages for the `<active_agent/>` marker, reading `content` and `sections` (guard.ts). The AsyncLocalStorage probe from the previous audit is deleted.

The advisor call resolves the model through the registry, requires a credential-backed entry, calls `completeSimple` with `tools: []`, accepts only `stopReason: "stop"`, and strips four tiers of fake tool-call markup. Failures report to the TUI when one exists. Every path fails open.

The second system is scripts/hooks/*.mjs: Claude Code hooks that share lib.mjs plumbing. They share nothing with the extension at runtime. The model matches README and AGENTS.md except for the shipped-state contradiction recorded as F024.

## Things that look bad but are actually fine

- **`readFileSync` on every `turn_end` (config.ts:170).** The file is 154 bytes. The read is once per agent turn, and the per-dispatch read is the hot-reload design. An mtime check is the fix if a profile ever shows it.
- **`Boolean(system.toolsAdded || system.toolsRemoved)` treats empty arrays as declarations (prompt.ts:40-43).** The needless rebuild is a pure strip that produces the correct shape either way.
- **`markFired` runs before the child veto, so a vetoed boundary spends its slot (plan-turn.ts:104).** Same-session behavior, deliberate: a commit-time write would re-attempt a broken registry on every later turn. t9 pins it. The cross-session latch variant is an open question below, not a finding.
- **The hook blocklist stays narrow (gate.mjs:31-56).** `TRUNCATE`, `find -delete`, and `xargs rm` pass. The header documents the scope. Widening it belongs to an allowlist design, not to this hook.
- **Four regex passes over one reply (advisor.ts:181-198).** Linear scans over a single model message. No ReDoS shape exists in any pattern.
- **The full transcript ships on every gate (prompt.ts:77-81).** Deliberate. The advisor exists to catch drift from early decisions, and a tail window cannot see them.
- **Resolve failures notify on every gate-pass instead of latching (plan-turn.ts:108-110).** Credential state changes mid-session. A latch would hide recovery. One warning per interval is the honest rate.
- **tests/test.mjs is a 1,234-line flat file.** Section banners hold the structure, and one hand-rolled assert keeps output deterministic. Split it when it passes about 1,500 lines or when a second runner appears.
- **`{ok, reason}` vs `{ok, detail}` result shapes across modules.** The model call and the syntax check are different layers, and each is consistent within its layer.
- **`Date.now()` in prompt.ts:72 and in the t16 deadline bound.** Neither reaches test output. The determinism rule bans timestamps in output, not in message shapes or private measurements.
