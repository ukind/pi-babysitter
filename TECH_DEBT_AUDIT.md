## Architectural mental model

A Pi coding-agent extension, hub-and-spoke, now nine spokes. `index.ts` is the only runtime-loaded file and owns all I/O: the per-dispatch config read, the registry-bound thunks, one cadence latch, a fire counter, and two async slots (`advisorInFlight`, `heldAdvice`). Two handlers register: `turn_end` (blocking commit, or async detach under FR8) and `agent_before_settle` (the once-only async commit, deliberately without `continue`). Decisions live in pure cores: `planGate`, `planCommit`, `planSettle`, `planHostSupport`, `stampDetails` in plan-turn.ts, plus `planTrigger` in triggers.ts. The advisor call resolves the model through a credential gate, runs under one shared per-fire deadline, may loop over a read-only sandbox (`createSandbox`, `planRead` pure bound), may consult a specialist leg, admits only `stopReason: "stop"`, and strips four tiers of fake tool-call markup. Memory is a per-project JSON store beside the module, keyed by a slug+hash of the cwd, digested into the next fire's payload. Everything fails open; every failure shape is `{ ok, reason }` data.

The second system, `scripts/hooks/*.mjs`, is unchanged from the previous audit: Claude Code PreToolUse/PostToolUse hooks sharing `lib.mjs`, harness-agnostic, plain node, fail-open. The third system is new since the last audit: `eval/runner.mjs`, the sanctioned second runner, replaying golden fixtures per pillar through the real pipeline and gating CI on the score table. README documents 17 config fields and matches the code defaults checked this run. The documentation layer (guidance file, AGENTS.md) is where the drift concentrated — see F029 and F034.

```js
const ROOT_LIKE_TARGETS = new Set([
  "/",
  "/.",

  "~/",
  "~/*",
  "/*",
  "*",
  ".",
  "..",

function isRootLikeTarget(token) {
  const target = token.replace(/^["']|["']$/g, "");

```

- **`markFired` runs before the child veto, so a vetoed boundary spends its slot (plan-turn.ts).** Still deliberate — a commit-time write would re-attempt a broken registry every later turn. t9 pins it.
- **Four regex passes over one reply (advisor.ts stripAdvisorMarkup).** Still linear scans over a single model message; no ReDoS shape in any pattern; the widened groups stay bounded.
- **The hook blocklist stays narrow (gate.mjs).** `TRUNCATE`, `find -delete`, `xargs rm` still pass; the header documents the scope. F035 extends the root-like rule; it does not widen the blocklist philosophy.
- **The async busy-slot fire is consumed silently (index.ts, the BOTH-slot guard).** A gate-pass while either async slot is busy burns the latch with no notify. Documented as the FR8 contract ("a consumed fire, never a queue"), commented as load-bearing, and reachable only at interval 1 inside one multi-turn run. A report here would warn every turn for a state the user configured; the failure mode is a missing advisory, not a wrong commit.
- **Two private `warnOnce` latches (config.ts, memory.ts).** The star topology forbids the sibling import a shared latch would need; duplication is the documented price of plain-node loadability.
- **The sandbox byte cap refuses a 70 KiB file instead of truncating (sandbox.ts).** The refusal names the counts; a silent truncation would show the advisor a lying prefix of a file. Refusal is the honest shape.
- **Substring-based eval scoring (`drift-caught` uses `content.includes`).** Loose pins are the point of a score gate, not a unit pin; the unit suite carries the exact-string pins.
- **`MEMORY_DIR_URL` is a mutable module-level URL (memory.ts).** The mutability is the documented test affordance, same as `CONFIG_URL`; production never writes the href; eval restores it in `finally`.
- **`stampDetails` values are strings (plan-turn.ts).** Deliberate: stable JSON round-trips and greppable session files; t24 pins the keys.
- **`protectedBranch`'s `[^:]*:` prefix is greedy (gate.mjs).** Git refspecs carry at most one colon, and the probe confirms `main:main`, `HEAD:refs/heads/main`, and `:main` block while `refs/tags/main` passes. No reachable mis-parse.
- **`config.example.json` carries the full `systemPrompt` copy (F005 reversal).** A deliberate, recorded reversal; the code default stays the single source and t7b bands it.
- **`Date.now()` at digest assembly and in message timestamps (memory.ts, prompt.ts).** Never reaches test output; the determinism rule bans timestamps in output, not in message shapes.
