## Architecture Insights

- **Fail-open everywhere** (.agents/rules/main.md:19): every failure path reports when a UI exists and returns undefined. F001 is the one path where fail-open for the turn still crashes the process later — the fix restores the invariant the comment at advisor.ts:233-234 already claims.

- **Type-only imports erase**: devDependencies constrain the type-check baseline only, never the host — the decisive fact for F008.
